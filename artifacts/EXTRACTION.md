# Extracción de JAR

Cada JAR entregado fue inspeccionado como ZIP Java. Se identificaron sus clases compiladas, plugin.yml y config.yml.

CameraOperator 2.1.1 contiene CameraCommand, CameraData, CameraListener, CameraOperatorPlugin, CameraPoint, CameraSession, LiveMode, Shot y SliderPath, además de las clases internas de CameraData/CameraSession.

CameraAnimations 1.0.0 contiene AnimationCommand, AnimationData, AnimationListener, AnimationPlayback, AnimationProject, AnimationSegment, CameraAnimationsPlugin, CameraPoint y Easing.

El código Java reconstruido debe entenderse como una reconstrucción basada en bytecode y recursos, no como recuperación literal del fuente original.
